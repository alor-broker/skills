# Liquidity scenarios

Use the data already in scope. For an illustrative case, choose transparent round assumptions and label them as illustrative; for an organization-specific case, preserve the source and coverage of each input.

Include at least:

- a base cash-flow schedule, coverage statement, and valuation date;
- an earlier-payment or higher-outflow timing shock;
- a rate-curve shock, including a non-parallel move when material;
- a credit-spread or default shock for risky assets;
- a market-liquidity shock with longer sale horizons and explicit haircuts;
- a combined scenario and the strongest model objection.

Distinguish accounting value, market value, expected cash flow, executable proceeds, and cash available by date. State separately whether the work is an internal scenario, an illustrative sensitivity, or an implementation of a named regulatory method.
