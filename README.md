# Skills

Коллекция навыков для Veles и других клиентов, поддерживающих формат Agent Skills. Навыки добавляют инструкции и вспомогательные инструменты для работы с внешними сервисами, научными данными и веб-приложениями.

## Добавление навыка

Каждый навык размещается в отдельном каталоге и должен соответствовать [спецификации Agent Skills](https://agentskills.io/specification). Имя каталога должно совпадать с полем `name` в `SKILL.md`. Дополнительные скрипты размещаются в `scripts/`, а справочные материалы — в `references/`.

### Секреты Veles

Секреты объявляются в метаданных `SKILL.md`. `requires.env` содержит обязательные значения, а `secrets.env` — необязательные:

```yaml
metadata:
  veles:
    requires:
      env: [API_TOKEN]
    secrets:
      env: [OPTIONAL_TOKEN]
```

В репозиторий добавляются только имена секретов, но не их значения. Veles хранит значения отдельно в зашифрованном хранилище и передаёт навыку через переменные окружения.

### Конфигурация Veles

Обычные настройки описываются в корневом `config.json` навыка:

```json
{
  "veles": {
    "endpoint": {
      "type": "string",
      "required": true
    },
    "retries": {
      "type": "number",
      "defaultValue": 3,
      "minValue": 0,
      "maxValue": 10
    }
  }
}
```

Для каждой настройки поддерживаются следующие поля:

| Поле | Применимость | Описание |
| --- | --- | --- |
| `type` | всегда | Обязательный тип значения: `string` или `number`. |
| `required` | всегда | Обязательность значения (`true` или `false`); по умолчанию `false`. |
| `defaultValue` | всегда | Значение по умолчанию соответствующего типа, удовлетворяющее всем ограничениям. |
| `minValue` | `number` | Минимальное числовое значение. |
| `maxValue` | `number` | Максимальное числовое значение. |
| `minLength` | `string` | Минимальная длина строки — неотрицательное целое число. |
| `maxLength` | `string` | Максимальная длина строки — неотрицательное целое число. |
| `pattern` | `string` | Регулярное выражение, которому должна полностью соответствовать строка. |

Имя настройки должно быть непустой строкой без точек. `minValue` не может превышать `maxValue`, а `minLength` — `maxLength`. Числовые и строковые ограничения нельзя смешивать; неизвестные поля отклоняются валидатором.

Репозиторий можно подключить как маркетплейс Veles либо установить нужный каталог навыка отдельно.

## Консультант по питанию

Два навыка для личности `nutrition-adviser` дают доступ к сведениям о пищевой ценности, но не заменяют медицинские рекомендации:

| Навык | Назначение |
| --- | --- |
| `pp-nutrition` | Поиск состава обычных продуктов в USDA FoodData Central, сравнение на общей основе и расчёт состава блюда. |
| `pp-open-food-facts` | Чтение состава, аллергенов и пищевой ценности упакованных продуктов по штрихкоду через Open Food Facts. |

Навыки адаптированы из `mvanhorn/printing-press-library` с фиксацией исходной версии в каждом `SKILL.md`. Вместо внешних программ они используют собственные ограниченные скрипты на Python из стандартной библиотеки, поэтому отдельных требований к командным программам в метаданных нет.

Чтение Open Food Facts не требует ключа. USDA FoodData Central допускает общий демонстрационный ключ с низким лимитом; необязательный бесплатный `FDC_API_KEY` хранится только в зашифрованных секретах Велеса. Скрипты не содержат пищевой дневник, локальное хранение ключей, вебхуки или изменение записей внешних сервисов. Долговременные данные остаются под управлением Велеса.

## Финансовая аналитика для НПФ

Набор предназначен для финансовых вопросов руководителя управляющей компании: стратегии пенсионных активов, согласования активов и обязательств, инвестиционного риска, качества отчётности, анализа эмитентов и рыночных сценариев. Навыки используют имеющийся контекст, но сами не запрашивают раскрытие портфелей, обязательств, лимитов, договоров, внутренних отчётов, сведений о сделках или данных счетов.

| Навык | Назначение |
| --- | --- |
| `npf-pension-asset-strategy` | Сводный разбор стратегии пенсионных активов и вариантов решения. |
| `npf-alm-liquidity-scenarios` | Анализ согласования активов и обязательств и управления ликвидностью. |
| `npf-investment-risk-stress-testing` | Методы инвестиционного риска и стресс-сценарии. |
| `npf-reporting-quality-review` | Проверка определений, происхождения и воспроизводимости показателей. |
| `npf-issuer-investment-analysis` | Анализ эмитента и ценной бумаги. |
| `npf-market-scenario-analysis` | Сценарии по ставкам, инфляции, валюте, бюджету, сырью и рыночной ликвидности. |

Навыки не требуют секретов, соединений с брокерскими или банковскими счетами и отдельных программ. Для личности Велеса их рекомендуется устанавливать в её собственный каталог `personalities/npf-asset-management-finance-adviser/skills/`, чтобы специализированная финансовая маршрутизация не применялась ко всем остальным личностям рабочей области.

## Создание песен

Два навыка для написания и редактирования песен с проверкой смысла, естественности языка, ритма и припева:

| Навык | Назначение |
| --- | --- |
| `songwriting` | Песни разных жанров и тем: текст, драматургия, певучесть, редактура и музыкальный бриф. |
| `birthday-lyrics` | Лиричные поздравления с днём рождения: личные детали, благодарность, сильный припев и светлый финал. |

Навыки работают независимо и не требуют ключей или программ. Справки содержат рекомендации для Lyrics/Styles; подготовка текста и настроек сама по себе не создаёт аудиозапись. В поздравительном навыке отдельно разобран пример песни маме от дочери, без закрепления этого адресата, рассказчика или жанра для всех заказов.

## Публикации в блоге

Навык [`blog`](blog/SKILL.md) готовит записи, загружает изображения, публикует согласованный материал и читает созданную запись для проверки. Используются стандартный программный интерфейс WordPress (`wp/v2`) и пароли приложений; дополнительное расширение не требуется.

Публичный адрес хранится в `skills.entries.blog.config.blogUrl` основной конфигурации Велеса. Если служебный адрес отличается, задайте `apiBaseUrl` там же. Логин задаётся в обычном поле `skills.entries.blog.config.username`, а пароль приложения — только в зашифрованном секрете `skills.blog.env.BLOG_APP_PASSWORD`. Старый секрет `BLOG_USERNAME` не используется. По умолчанию используется адрес `<blogUrl>/wp-json/wp/v2`; явный адрес `/author-app/v1` включает способ Writer Studio: пароль приложения обменивается на временный токен в памяти. Корневой `blog/config.json` описывает только поля настройки.

[Настройка и использование на русском языке](blog/references/setup_ru.md). Команда `check-auth` проверяет доступ без создания публикаций; в режиме Writer Studio для этого создаётся сеанс авторизации. Без `--execute` команды создания записи и загрузки изображения лишь показывают локальную заготовку; неопределённый результат отправки не вызывает автоматического повтора. Автономные проверки находятся в `tests/test_blog.py` и не обращаются к действующему сайту.

Для навыка обязательны показ полной записи и отдельное подтверждение перед публикацией. Видео MOV предварительно преобразуются в MP4 через ffmpeg с сохранением оригинала; при необходимости разрешена установка ffmpeg из доверенного источника. Удаление записей, вложений и файлов запрещено даже по просьбе пользователя. Эти правила заданы в инструкциях навыка.
