# Skills

Коллекция навыков для Veles и других клиентов, поддерживающих формат Agent Skills. Навыки добавляют инструкции и вспомогательные инструменты для работы с внешними сервисами, научными данными и веб-приложениями.

## Добавление навыка

Каждый навык размещается в отдельном каталоге и должен соответствовать [спецификации Agent Skills](https://agentskills.io/specification). Имя каталога должно совпадать с полем `name` в `SKILL.md`. Дополнительные скрипты размещаются в `scripts/`, а справочные материалы — в `references/`.

### Секреты Veles

Секреты объявляются в метаданных `SKILL.md`. `requires.env` содержит обязательные значения, а `secrets.env` — необязательные:

```yaml
metadata:
  veles:
    requires:
      env: [API_TOKEN]
    secrets:
      env: [OPTIONAL_TOKEN]
```

В репозиторий добавляются только имена секретов, но не их значения. Veles хранит значения отдельно в зашифрованном хранилище и передаёт навыку через переменные окружения.

### Конфигурация Veles

Обычные настройки описываются в корневом `config.json` навыка:

```json
{
  "veles": {
    "endpoint": {
      "type": "string",
      "required": true
    },
    "retries": {
      "type": "number",
      "defaultValue": 3,
      "minValue": 0,
      "maxValue": 10
    }
  }
}
```

Для каждой настройки поддерживаются следующие поля:

| Поле | Применимость | Описание |
| --- | --- | --- |
| `type` | всегда | Обязательный тип значения: `string` или `number`. |
| `required` | всегда | Обязательность значения (`true` или `false`); по умолчанию `false`. |
| `defaultValue` | всегда | Значение по умолчанию соответствующего типа, удовлетворяющее всем ограничениям. |
| `minValue` | `number` | Минимальное числовое значение. |
| `maxValue` | `number` | Максимальное числовое значение. |
| `minLength` | `string` | Минимальная длина строки — неотрицательное целое число. |
| `maxLength` | `string` | Максимальная длина строки — неотрицательное целое число. |
| `pattern` | `string` | Регулярное выражение, которому должна полностью соответствовать строка. |

Имя настройки должно быть непустой строкой без точек. `minValue` не может превышать `maxValue`, а `minLength` — `maxLength`. Числовые и строковые ограничения нельзя смешивать; неизвестные поля отклоняются валидатором.

Репозиторий можно подключить как маркетплейс Veles либо установить нужный каталог навыка отдельно.
