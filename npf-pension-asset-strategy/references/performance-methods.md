# Performance methods

## Before comparing published returns

Record the portfolio regime, reporting period, annualized or period return, currency, gross or net basis, fee treatment, valuation convention, cash-flow treatment, benchmark, inflation measure, source date, and version or revision status.

Do not compare:

- pension savings with pension reserves; within pension reserves, non-state pension provision with the long-term savings program without an explicit reconciliation;
- gross returns with net returns;
- time-weighted returns with money-weighted returns;
- nominal returns with real returns;
- different periods, currencies, or observation frequencies;
- a market index with an investable portfolio without explaining fees, taxes, liquidity, rebalancing, and asset eligibility.

## Calculations

- For a period with no external flows, simple return is `(ending value - beginning value) / beginning value` when the valuation basis is consistent.
- When external flows exist, use the governing methodology or a chain-linked return from valuations immediately around each flow. If flow dates and the required valuations are unavailable, state that the return cannot be reconstructed.
- Geometric annualization: `(1 + cumulative return)^(year_fraction^-1) - 1`; do not annualize short or irregular periods without a clear reason.
- Approximate real return: `(1 + nominal return) / (1 + inflation) - 1`; identify the exact inflation series and period.
- Excess return: portfolio return minus a defined benchmark over the same period and basis.

Show formulas, sourced inputs, transformations, and rounding. If the available data do not expose the necessary cash flows, fee basis, or valuation dates, state that the requested comparison cannot be reproduced.
